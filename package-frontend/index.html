Demo Integrasi Frontend

Halaman ini mendemonstrasikan widget percakapan AI mandiri dengan sapaan awal personal, penerbitan tiket resmi di Jira Service Desk (Project SUP), dan sistem alert internal.

✨ 3 Fitur Utama yang Diaktifkan:

  • 👋 Sapaan Awal Personal: Saat chat dibuka, bot otomatis menyapa dengan nama user (misal "Halo Budi Pratama! Ada yang bisa kami bantu?") dan menampilkan shortcut tombol cepat.
  • 🌐 Terintegrasi Jira Service Management (SUP): Kendala yang dilaporkan otomatis dibuatkan tiket resmi di instance Atlassian Anda (imtekservice.atlassian.net / Project: SUP) dengan tautan langsung di bubble chat!
  • 📚 SOP Panduan Non-Teknis Otomatis: Bot dibekali panduan solutif untuk kendala non-teknis (Login & Lupa Password, Ekspor Laporan, Status Pembayaran, dan form verifikasi investigasi selisih data).
  • 🚨 Multi-Channel Incident Alert: Notifikasi instan terkirim serentak ke Slack Channel Tim Internal (Block Kit), Telegram Bot, dan WhatsApp Gateway.

Sematkan script berikut pada aplikasi web Anda:

<script src="/path-to/chat-widget.js" data-webhook="http://localhost:5678/webhook/chat-entry" data-user-id="USER-123" data-user-name="Budi Pratama" data-bot-name="Asisten Virtual"> </script>

Klik tombol bubble biru 💬 di pojok kanan bawah untuk menguji sapaan dan coba ketik: "Min, fitur transaksi tidak bisa diakses" atau klik tombol 🚨 Lapor Kendala Fitur.
