Demo Integrasi Frontend

Halaman ini mendemonstrasikan widget percakapan AI mandiri. Cukup sematkan script berikut pada aplikasi web Anda:

<script src="/path-to/chat-widget.js" data-webhook="/api/webhook/chat-entry" data-user-id="USER-123"> </script>

Klik tombol bubble biru di pojok kanan bawah untuk memulai percakapan.

Catatan: Widget chat publik ini tidak memuat token dashboard, sehingga kuota dan token analytics tetap terpisah dan aman khusus untuk admin.
