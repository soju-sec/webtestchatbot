Halaman ini mendemonstrasikan widget percakapan AI mandiri. Cukup sematkan script berikut pada aplikasi web Anda:

<script src="/path-to/chat-widget.js" data-webhook="http://localhost:5678/webhook/chat-entry" data-user-id="USER-123"> </script>
